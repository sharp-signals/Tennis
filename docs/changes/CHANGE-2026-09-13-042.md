# CHANGE-2026-09-13-042 — Incremental Pre-Live Runs

## Regra operacional

Em execuções adicionais o Fenzobot só publica um relatório/e-mail/Telegram
quando a fixture é nova, quando um mercado pendente passa a ter Moneyline
bilateral válida ou quando a maior mudança de probabilidade implícita desde o
último relatório é de pelo menos **3,0 pontos percentuais**.

Um jogo válido cujo preço não mudou materialmente é apenas revalidado no
mercado e não cria relatório duplicado. Um preço que desapareça temporariamente
também não apaga o relatório válido já publicado; a fila de mercado pendente
trata a reconsulta separadamente.

## Agendamento

`scripts/google_apps_script/prelive_scheduler.gs` contém o agendador autónomo
para 06:30, 11:30, 15:30 e 18:30 em `Europe/Lisbon`, sem depender de o
computador estar ligado. Usa somente o `GITHUB_TOKEN` já configurado no Apps
Script e o `workflow_dispatch` do GitHub.

Não há Claude, The Odds API nem alteração do Odds Movement Monitor nesta
mudança.
