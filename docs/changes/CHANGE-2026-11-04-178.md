# CHANGE-2026-11-04-178 — protótipo visual do relatório contextual

**Nível:** 3 — workflow e apresentação de pricing

## Alteração

- adiciona contrato visual versionado para o relatório contextual v2;
- gera view-model apenas a partir dos ledgers congelados;
- apresenta probabilidades, fair odds, intervalos, benchmark e famílias;
- distingue ausência observada de dados indisponíveis;
- produz previews HTML num artefacto privado do workflow;
- mantém site, relatórios operacionais, Telegram, PAPER e GREEN intocados.
- impede que uma execução com ledgers temporários leia acidentalmente o
  benchmark real de mercado.

## Garantia

O mercado nunca entra no cálculo da previsão. O preview apenas junta a primeira
cotação válida depois de a previsão estar congelada. Não existe botão, mensagem
ou estado que autorize uma entrada.
