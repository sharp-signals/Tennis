# CHANGE-2026-09-27-060 — Fix GitHub Actions Runner Temp Context

Estado: **IMPLEMENTED / AWAITING BRAIN REVIEW**

Nível: 1 — workflow bugfix

Base inicial verificada: `fa8c488c0a3df29754524e318db642ffc102d873`

## Objetivo

Corrigir a validação do workflow `tennis-bot.yml`, que falhava antes de criar
qualquer job porque o contexto `runner.temp` era avaliado no `env` do job.

## Implementação

- removida a expressão `${{ runner.temp }}` de `jobs.run-bot.env`;
- acrescentado o step `Configurar manifesto temporário` depois do checkout e
  setup de Python e antes da execução do bot;
- o step usa `$RUNNER_TEMP` já dentro do runner e grava
  `FENZOBOT_REPORT_NOTIFICATION_MANIFEST` em `$GITHUB_ENV`, tornando o mesmo
  caminho disponível aos steps seguintes.

## Preservações

Não foram alterados `src.report_notifications`, readiness HTTP 200 + SHA-256,
timeout de publicação, notification fingerprint, checkpoint durável, Telegram,
email, PAPER, análise, pricing, PR #167, CHANGE-059 ou scheduler Apps Script.

Não houve chamadas externas, SMTP, Telegram, RapidAPI, LLM ou run operacional.

## Validação

O contrato do workflow comprova que o contexto `runner.temp` já não é usado no
nível do job, que `$RUNNER_TEMP` é exportado através de `$GITHUB_ENV` antes do
bot e que a ordem `bot → publish → readiness → notify → calibration` permanece.

Resultados finais são registados na PR do CHANGE-060.
