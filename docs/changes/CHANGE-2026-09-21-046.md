# CHANGE-2026-09-21-046 — GREEN Monetization €10 Flat-Stake

Estado: IMPLEMENTED / PR REVIEW REQUIRED
Nível: 2 — behaviour / validation / reporting
Issue: #149

## Decisão implementada

`GREEN_MONETIZATION_V1` responde à pergunta observacional “Se tivéssemos
apostado €10 em cada aposta GREEN auditável, quanto teríamos ganho ou perdido?”.
A vista é histórica/experimental, não usa dinheiro real e não demonstra edge
futuro.

A carteira técnica append-only `data/paper_trades.json` é o baseline inicial
dos GREEN Moneyline: o contrato operacional só cria estas entradas perante
`EDGE_POSITIVE`. O agregado não redefine GREEN, não altera PAPER e não usa rows
manuais GUERRA. `GUERRA_SELECTION_V1` permanece preservado no dashboard e na
documentação como histórico **SUPERSEDED**.

## Contrato de dados

O agregado canónico fica em
`data/validation/green-monetization-v1.json` e é reconstruído offline sempre que
o dashboard é gerado. Cada leg exige snapshot, instante ex ante, mercado,
seleção, odd decimal factual e, para mercados não Moneyline, linha explícita.
Settlement ausente é pendente; settlement presente tem de ser WIN, LOSS, VOID
ou PUSH.

Deduplicação: `snapshot_key + market_type + line/selection`.

- WIN: `€10 × (odd − 1)`;
- LOSS: `−€10`;
- VOID/PUSH: `€0`, mas a leg conta como resolvida;
- pendente: `€10` de exposição, sem P/L realizado;
- sem odd/linha/prova temporal, duplicado ou outcome desconhecido: exclusão
  tipada, nunca reconstrução nem zero inventado.

São aplicados cumulativamente:

- `data/paper_integrity_exclusions.json`;
- `data/validation/market-integrity-exclusions-v1.json`.

## Dashboard

O primeiro bloco visível, tanto em dia como em global, apresenta em grande o
P/L GREEN em euros, stake resolvida, exposição pendente, ROI, legs
resolvidas/pendentes/excluídas, W–L/void, status e breakdown por mercado.
Inclui o aviso inequívoco de simulação histórica/experimental. O painel GUERRA
é rebaixado para um detalhe colapsável `SUPERSEDED` e não alimenta a nova
série.

## Limites preservados

Não foram alterados definição de GREEN, pricing, thresholds, settlement,
SHADOW/PAPER/REAL, odds, APIs, LLM, secrets ou custos. Não existem chamadas
externas novas. Nenhuma versão HTML histórica foi alterada.
