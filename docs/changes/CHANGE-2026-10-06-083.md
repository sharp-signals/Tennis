# CHANGE-2026-10-06-083 — Codificação robusta do sync PAPER

Estado: IMPLEMENTADO  
Nível: 1 — correção de integração Apps Script

## Problema

O Apps Script podia receber HTTP 422 do endpoint GitHub Contents, com
`content is not valid Base64`, antes de publicar o agregado PAPER.

## Correção

O conteúdo passa a ser codificado a partir dos bytes de um Blob UTF-8, em vez
da sobrecarga de texto da API Apps Script. O payload, o caminho publicado e as
regras de agregação mantêm-se inalterados.

## Validação

- Teste Node confirma a codificação explícita de bytes UTF-8.
